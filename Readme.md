# E-Commerce-API

Project:  E-commerce API 
Welcome to the repository for the  E-commerce Backend API.
This project is built using Node.js and Express.js, prioritizing clean code, a structured architecture (similar to MVC), and the efficient use of Middlewares for handling requests and validation.✨ Key FeaturesBased on the file structure, this application provides a comprehensive set of E-commerce functionalities:Full Product Management: Complete CRUD (Create, Read, Update, Delete) operations for products (productController).Authentication & User Management: User sign-up, login, profile management, and authorization (authController, userController).Shopping & Wishlist: Functionality to manage shopping carts and user wishlists (cartController, wishlistController).Categorization: Management of categories and subcategories (categoryController, subCategoryController).Order & Coupon System: Handling customer orders and managing promotional coupons (orderController, couponController).Data Validation: Dedicated validation layer for all major entities (e.g., authValidator, productValidator).Review System: Allowing users to submit and manage reviews (reviewController).Robust Error Handling: Custom error handling using ApiError and errorMiddleware.Image Uploads: Dedicated middleware for handling file and image uploads (uploadimageMiddleware).🛠️ Technologies UsedNode.js: The primary runtime environment.Express.js: The web application framework used to build the API.
Database:  MongoDB

📂 Project StructureThe project is organized to promote modularity, maintainability, and clarity:FolderDescriptionConfigApplication configuration settings (e.g., DB connection).ControllersContains the core business logic for handling requests and preparing responses.MiddlewaresFunctions executed before or after the controllers (e.g., error handling, authentication checks, file upload processing).ModelsDatabase schemas and models (e.g., User, Product, Order).RoutesDefines the API endpoints and directs them to the appropriate controllers.UtilsUtility functions and helper classes (e.g., ApiError for custom errors, apifeature for filtering/pagination, sendEmail).validatorDedicated files for input data validation logic (authValidator, productValidator, etc.).uploadsStores uploaded files, primarily images.server.jsThe main entry point of the application.🤝 ContributingContributions are always welcome!
